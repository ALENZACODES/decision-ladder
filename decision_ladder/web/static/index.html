How Decision Ladder works

A mortgage file climbs eleven rungs, bottom to top: intake, screening, documents, collateral, insurance, B-20 qualification, lender fit, market, exit cost, compliance, decision. Each rung is a deterministic, tested calculator that returns PASS, REFER, FAIL or SKIP. No language model runs inside a rung, so a decision can always be reproduced.

Where NVIDIA Nemotron does the work

  • Nemotron 3 Super (reasoner) plans tool calls in the copilot and writes the broker decision memo from the rung results.
  • Nemotron 3 Nano (fast) turns client emails into structured files in JSON mode and drafts short borrower messages.
  • Both run on Nebius Token Factory through its OpenAI-compatible API.

Guarantees

  • Provenance verifier: every dollar figure and rate in a memo or answer is matched to a tool result or the user's own input. Nemotron gets one repair turn; anything still untraced is marked [unverified].
  • Path to yes: when a file fails the stress test, solvers search for the max price, min down payment, debt payoff and income needed, each re-checked by the same test that failed it.
  • Guardrail: borrower messages are blocked if they quote rates, promise approval, apply pressure or ask for SINs, passwords or card numbers.
  • Live research: Tavily searches official Canadian sources (Bank of Canada, OSFI, FSRA, CMHC, Canada.ca) for anything newer than the rate book, with URLs.

Engines

  • OSFI B-20 stress test with GDS/TDS; Dec 2024 insured-mortgage rules; CMHC-style premium schedule.
  • Lender-method prepayment penalties (posted-minus-discount, CIBC add-back, present value) from Renewal Radar, with comparison-term sensitivity, using each Big-6 bank's own captured posted rates.
  • Rate book: Bank of Canada Valet (policy rate, prime, GoC curve, effective lending rates) plus rates captured from bank websites.
  • Renewal shock, offer comparison, switch check and a renewal-book priority queue.

Not lending, legal or compliance advice. Outputs are estimates for a licensed mortgage broker to confirm. Identity screening is not performed unless a licensed list is connected.
