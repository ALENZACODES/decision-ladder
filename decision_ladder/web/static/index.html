How the Mortgage OS works

Fourteen of John Khan's own mortgage, housing and rates projects run inside one system as modules. A client file climbs a 17-rung ladder across the whole lifecycle (lead, documents, pre-qualification, underwriting, property, closing, market, servicing, commercial, compliance, decision). Each rung is computed by one of those apps' own tested code and returns PASS, REFER, FAIL or SKIP. No language model runs inside a rung, so every decision can be reproduced.

Three NVIDIA Nemotron tiers on Nebius Token Factory

  • Nemotron 3 Nano routes each copilot question to the lifecycle stages it touches (so Super only sees those apps' tools), extracts files from client emails and documents in JSON mode, and drafts client messages.
  • Nemotron 3 Super plans and runs the tool calls across the apps.
  • Nemotron 3 Ultra writes the credit decision memo over the whole journey (Super takes over if Ultra is not available to the key).
  • All three are called through Token Factory's OpenAI-compatible API. The OS deploys as a Nebius Serverless AI endpoint; the nightly renewal-book scan runs as a Nebius Serverless AI job.

Guarantees

  • Cross-checks: where two or more of the apps compute the same quantity (land transfer tax, insurance premium, qualifying rate and payment, renewal payment, IRD penalty), all of them run and must agree; known method differences are labelled, never hidden.
  • Provenance verifier: every figure in a memo or answer is matched to a tool result or the user's own input. Nemotron gets one repair turn; anything still untraced is marked [unverified].
  • Path to yes: when a file fails the stress test or comes up short on closing day, solvers find the price, down payment, debt payoff or income that works, each re-checked by the same test.
  • Grounded extraction: a value from an email or document is kept only if its quoted words appear in the source.
  • Guardrail: client messages are blocked if they quote rates, promise approval, apply pressure or ask for SINs, passwords or card numbers.
  • Tavily: Search reads official Canadian sources (Bank of Canada, OSFI, FSRA, CMHC, Canada.ca) with URLs; Extract reads each bank's own rate page to confirm the rate book is current.

The apps inside

  • Renewal Radar (letter X-Ray, lender-exact penalties, switch pathway, negotiation script, renewal plan, broker book review), MortgageLoanOps (B-20, insured rules, guardrail).
  • Benchmark Home Value and Canada Home Value (local benchmark prices, postal-area values, purchase indexing), the Canada Housing Affordability Index 1980-2026.
  • Canadian Mortgage Calculator Suite, Cash to Close, Mortgage Decision Lab, Loan File Pre-Underwriting Check, Doc Quest.
  • Renewal Check, Renewal Shock Radar, Canada's Rate Cycle 2015-2026, Private Credit Deal Screener.

Not lending, legal or compliance advice. Outputs are estimates for a licensed mortgage broker to confirm. Identity screening is not performed unless a licensed list is connected.
