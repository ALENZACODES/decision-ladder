# Image prompt pack for Decision Ladder

127 prompts. Paste one prompt per ChatGPT message. Save each image with the exact file name under `docs/images/` (for example `docs/images/hero/readme-banner.png`) and send them back; I wire them into the app, README, video and Devpost.

Rules baked into every prompt: no text in the image (titles are added afterwards so they are spelled right), no logos (use the official NVIDIA / Nebius / Tavily marks from their press kits instead), no real people. Real app screenshots must stay real screenshots: never generate a fake UI or fake numbers.

To reach 300-500 images: generate 3 variations of every A, D, E and H prompt and pick the best one.
