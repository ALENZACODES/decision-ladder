Method

  • LTV = loan / appraised value. DSCR = NOI / annual debt service. Debt yield = NOI / loan.
  • Exit value = NOI grown over the term / (going-in cap rate + exit cap shift). Exit LTV = balloon balance / exit value.
  • Score weights: LTV 25%, DSCR 25%, exit LTV 25%, debt yield 15%, sponsor 10%. Thresholds are a personal screening framework, not an industry standard.
  • All deals are fictional examples built to show the method.
