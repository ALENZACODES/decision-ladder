Benchmark Home Value

A home value estimator for all 17 million addresses in Canada. It does what paid valuation tools and lender AVMs do, publishes its own accuracy test in full, and costs nothing: no account, no API keys, no paid data.

Start it

  1. Online: open the website link on the GitHub page. On your computer: double-click Start Benchmark Home Value.bat in this folder. Your browser opens the app; keep the small black window open while you use it.
  2. Type an address (for example 24 Mountain Cir SE, Airdrie) and press Enter, or pick it from the list.
  3. Optional, any time: double-click Update live data.bat to pull today's Bank of Canada rates and save the chart library for offline use.

The launcher needs no install. It uses Python if your PC has it (tested on a Windows PC with Python 3.14), and otherwise PowerShell, which every Windows PC has. With Python it also runs a small relay so the app can reach the City of Toronto and OpenStreetMap data that browsers can't call directly. If Windows shows a blue "Windows protected your PC" box the first time, choose More info → Run anyway; the scripts are plain text you can open in Notepad.

The proof: tested on real homes

17,250,061addresses in the National Address Register, every one with an estimate
974,500homes backtested, 7.37 million predictions from 1.22 million assessment records
4.95%median error for houses (78% within 10%); 6.3% across all homes
0 of 492,328streets typed back in landed on the wrong home (1.1% did before the fix)

Each home was priced from every earlier assessment it had, using only what was known at the time, then checked against what the city assessed later (Calgary, Edmonton, Vancouver, the rest of Alberta and BC). Condos are harder (15.2% median error) and Vancouver and the rest of BC are weaker than Alberta; the app says so, and shows each address's own confidence score from these tests. Every chart and table in the Backtest section can be saved as PNG and CSV, or all at once as a zip.

Free, public sources

Property and place

  • Statistics Canada National Address Register (all 17.25 million addresses)
  • Municipal open assessment rolls: Calgary, Edmonton, Vancouver, Winnipeg and other AB and BC municipalities
  • 2021 Census block profiles and postal-area home values
  • Open Database of Educational Facilities; Ontario EQAO results

Market and money

  • Regional price index shaped on public CREA and board benchmark history
  • CMHC Rental Market Survey
  • Bank of Canada Valet API (rates)
  • Statistics Canada Uniform Crime Reporting Survey (Crime Severity Index, July 2026)
  • Toronto Police Service Public Safety Data Portal; City of Toronto building permits
  • OpenStreetMap (everyday places nearby)
  • Statistics Canada population estimates and Labour Force Survey
  • Environment Canada heating degree-day normals

Honest limits

Values come from public assessments, the Census and regional benchmarks, not sold listings, so this is not an appraisal. Accuracy is tested only where cities publish assessment histories (Alberta and BC); elsewhere the confidence score says the estimate rests on Census and benchmark data. Rent, heating, lending and cottage figures use stated typical assumptions shown on each card. Ideas that need large outside data, paid licences or image processing (satellite footprints, renovation detection from space, flood layers drawn on the map, search-trend nowcasting, sold MLS prices, title and ownership, LiDAR scanning inside the app) are not in this version. Neighbourhood-level crime is live for Toronto; other cities use the Statistics Canada metro index plus a link to their police service's own map.
